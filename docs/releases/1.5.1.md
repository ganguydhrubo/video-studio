## Takebloom 1.5.1

- Replaced the empty decorative frame on Create with a working source-video preview. Choose a clip to play it locally; select another filename to preview that clip.
- Native file selection reads original clips directly, without a browser-copy step. Only files explicitly selected through the picker can be previewed outside the project workspace.
- Clearer, more compact Create layout and local-file wording, with the existing cinematic opening and light animated workspace retained.
- No arbitrary file-size cap. Browser copies stream in 1 MiB chunks; a 113 MiB regression test verifies the reported failure size. Disk space and processing time still matter.
- Interrupted copies are not accepted as completed videos. File-copy failures now show a reason and explain when an old page must be reopened after an app update.

The native picker avoids that old transfer path.

Windows 10/11 x64 intended; unsigned installer. Existing projects/settings/models are preserved. Optional tools and models may need separate downloads. Video processing is local; online AI review, if enabled, sends transcript text to the selected provider.
