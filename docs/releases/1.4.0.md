## Video Studio 1.4.0

A calmer desktop workspace with recognisable AI-provider icons, clear cards and simple editing progress.

- Opens in a separate Edge app window, without normal browser tabs and address bar. Uses the default browser if Edge is unavailable.
- Native Windows file selection reads the chosen clips directly. Drag-and-drop still makes a local working copy.
- Friendly stage messages, editing illustrations and milestones tied to completed work. Technical logs stay collapsed.
- Fixed footage-analysis stage tracking and the elapsed timer after a job ends. Reopening a running project reconnects to its progress.
- System cards load independently. Slow optional tool checks run in the background and share cached results.
- Windows builds and smoke tests run in GitHub Actions. Version tags publish the installer, portable zip and checksums.

### Install

Download **VideoStudio-Setup-1.4.0.exe**, run it, then open **Video Studio** from the desktop or Start menu. Windows 10/11 x64 is the intended target; this release was locally checked on Windows 11. The installer is unsigned.

The app includes its Python runtime, NumPy and Pillow. FFmpeg, speech/voice models and other editing tools are detected and set up separately. A fresh PC needs internet for missing tools/models. Optional AI uses the recipient's own accounts. This is not an everything-included offline installer.

Files are processed on the user's PC. Nothing is automatically published. Optional online AI review sends transcript text to the selected provider; choose AI Off to keep planning local. Updates preserve projects and settings.

Provider icons: LobeHub Icons (MIT), licence bundled with the app. No paid AI plan or performance benchmark is included or guaranteed.
