## Takebloom 1.5.0

Video Studio now has a new identity: **Takebloom — every take, beautifully told.**

- Warm light theme, teal/coral brand mark, clearer AI-provider cards and locally bundled provider icons.
- The original cinematic opening and animated world are preserved, adapted to the lighter visual identity. Reduced-motion preferences are respected.
- A separate app window opens through installed Microsoft Edge, with the default browser as fallback.
- Select footage directly from your PC through the native Windows picker. Drag-and-drop makes a local working copy.
- Friendly illustrated progress, real completed-stage milestones, accurate footage-analysis stage and an elapsed timer that stops on completion. Technical logs stay collapsed.
- Shared background tool checks prevent the System screen from hanging on slow optional tools.

### Install or update

Run **Takebloom-Setup-1.5.0.exe**, then open **Takebloom** from the desktop or Start menu. Existing projects, settings and models are retained. Internal data/install folders and the CLI retain their earlier names for compatibility.

Windows 10/11 x64 is the intended target; Windows 11 was used for local checks. The installer is unsigned. The app includes its Python runtime, NumPy and Pillow; missing FFmpeg, speech/voice models and optional editing tools need separate setup, usually with internet. This is not a fully offline bundle.

Your video is processed on your PC and is not automatically published or hosted publicly. Optional online AI story review sends transcript text to the chosen provider. Select AI Off for local planning. You use your own AI accounts; paid AI is used only when selected.

GitHub Actions tests each change, builds tagged Windows releases, smoke-tests the packaged app, and publishes installers/portable archives with checksums. Brand-name searches are not trademark clearance. Provider-icon licence: LobeHub Icons, MIT, included with the app.
