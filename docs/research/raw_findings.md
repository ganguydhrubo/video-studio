# Raw findings: open-source engines for a local-first Windows CLI video tool

Researched 2026-11-15. Repo metadata (SPDX, archived flag, last push, latest release) was pulled live from the GitHub REST API (`gh api repos/<owner>/<repo>` and `/releases/latest`). npm data came from `npm view`. Everything else came from the official docs/sites linked below.

- **UNVERIFIED** = I could not confirm it from a primary source this session.
- "Activity" is based on the last push date. Active means a push within about 30 days, slow means more than 6 months without a release, and stale means more than 12 months without a push.
- Licence note: when you **invoke a separate process** (subprocess/CLI), GPL/LGPL obligations generally do **not** pass to your tool. They apply when you **link** the code (import it in-process or ship modified copies). If you **bundle/redistribute** the binaries in your installer, you must also ship their licence text and offer the corresponding source (GPL §6 / LGPL). None of this is legal advice.

## License surprises (summary)

1. **Remotion is source-available, not OSS.** It is free only for companies with 3 or fewer people. Draft 5.0 terms count contractors and ban BYO-code render services.
2. **gyan.dev FFmpeg builds are all GPLv3.** For an LGPL-only bundle use BtbN `lgpl` (no x264/x265).
3. **Piper is now GPL-3.0** (piper1-gpl); the MIT rhasspy/piper is archived. Voice licences are separate, some are NC, and late-2026 retrains reuse old file names.
4. **XTTS-v2 (Coqui) is non-commercial (CPML)**, and no commercial licence can be bought.
5. **Audacity 4.0 reportedly removed mod-script-pipe scripting** (secondary sources).
6. **Claude Code is proprietary.** Gemini, Codex, and Qwen are Apache-2.0.
7. **Qwen OAuth is no longer free and does not work headless.** Codex `--full-auto` was removed.
8. **edge-tts uses an unofficial Microsoft cloud endpoint.**
9. **Freesound API needs case-by-case permission for commercial use.**
10. **HyperFrames is Apache-2.0**, but its best render path needs chrome-headless-shell (auto-downloaded). System Chrome falls back to slower screenshot capture.
